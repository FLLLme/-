本页只在你的浏览器里调用 GitHub API，token 不会发送到任何第三方。 用途：定位「后台打开文章所有字段为空」到底断在哪一步。 请先在后台登录，再运行本页。

检测项说明

① token从 localStorage 取出登录令牌
② 目录列表GitHub Contents API 列出 content/posts/
③ 读文件（base64）Contents API 返回的 base64 内容能否正确解码 —— 这是 Decap 列表用的路径
④ 读文件（raw）请求 Contents API 里给出的 download_url（指向 raw.githubusercontent.com）—— 这一步在国内网络常被拦截
⑤ 行首校验文件内容是否以 --- 开头（Decap 靠这个判断 front matter，否则报 Unrecognized front-matter format）
