③ 日志怎么看

  1. 完全没有 MSG 行 → 弹窗从未向本页回传消息。多半是弹窗被拦，或 worker 回调页没有实现回传。
  2. 有 MSG 但 origin 不是 base_url → 来源不匹配，Decap 会丢弃该消息，握手静默失败。
  3. 只有 authorizing:github，之后再无动静 → 本页的回执没送达弹窗（弹窗引用失效）。
  4. 出现 authorization:github:error:… → token 交换失败，错误详情就在消息里。
  5. 出现 authorization:github:success:… → 握手成功，问题在别处。
