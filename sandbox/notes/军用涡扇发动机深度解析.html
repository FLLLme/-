1部件架构与数据入口

Military Jet Engine 对应 partType="Engine-Jet-Military-1"，中文名"军用喷气发动机"，走新版推进系统。

核心结论

存档只保存参数，不保存推力和油耗。 游戏每次按"满油门"求解热力学循环，再把推力/油耗按 coreThrottle^2.5 缩放。因此油门不改变 TSFC。

2热力学循环（站位 0–8）

JetEngineMath.ProcessParams 用固化常数求解简化涡扇循环，不含压气机/涡轮效率变量。

进气与压缩

// 进气总温总压 T01 = T∞ · ( 1 + 0.2 · min(M,1.4)² ) ram = M>1 ? 1 − 0.075·(M−1)^1.35 : 1 P01 = min( P∞ · ram · (T01/T∞)^3.5, 200000 ) // 风扇与压气机（指数 2/7 = 0.2857） T02 = T01 · FPR^(2/7) P02 = P01 · FPR T03 = T02 · CPR^(2/7) P03 = P02 · CPR T04 = T03 + max( burnerTemp − T03, 1 ) // ≈ 燃烧室温度 P04 = P03 · TPR · 0.88 // 0.88 = 固化压力损失

涡轮、加力与喷管

T08 = T02 · FPR^(2/7) P08 = P02 T05 = max( T04 − T03 + T02 − BPR·(T08−T02), 1 ) P05 = P04 · (T05/T04)^3.5 // 加力燃烧室（仅 ThrottleAfterburner > 0） ΔT_AB = min( ABTemp, T05+700 ) − ( T05+200 ) T06 = T05 + ThrottleAfterburner · ΔT_AB T08 = T06 // 加力加热外涵 P06 = P05 // 无喷管总压损失模型
注意：真实发动机加力只加热核心流，游戏里 T08=T06 把外涵也一起加热，这是简化模型的近似。

3推力、油耗与比冲

核心流量由进气面积与压力比决定，推力按"核心+外涵"两股流分别计算后求和。

喷速与燃空比

Ve_core = SafeSqrt( 2009.0174 · T06 · (1−(p∞/P06)^(2/7)) ) Ve_fan = SafeSqrt( 2009.0174 · T08 · (1−(p∞/P08)^(2/7)) ) FAR = [4.5·(T06−T05) + (T04−T03)] / [42806.9956 − (T04+T06−T05)] Vinlet = M · sqrt( 401.8035 · T∞ ) // 核心进气面积（来自 UpdatePerformance） FanRadius = 0.5 · size · baseSize CoreEntry = max( 0.05, FanRadius − 0.09·min(size,1) ) CoreArea = π · CoreEntry² / (BPR+1)

质量流、推力与油耗

Bflow = min( 0.75·sqrt(T06/T01)/(P06/P01), 1 ) k_flow = sqrt(0.004878) · 1.2^-3 ≈ 0.04041 m_core = CoreArea · Bflow · P06 / sqrt(T06) · k_flow m_fan = BPR · m_core ThrustNet = max(0, m_core·(Ve_core−Vinlet)) + max(0, m_fan·(Ve_fan−Vinlet)) TSFC = FAR / SpecificThrust FuelFlow = TSFC · ThrustNet Isp = ThrustNet / (FuelFlow · 9.81)
RamDrag 只作诊断，不再从净推力中扣除——进气动量损失已在 (Ve − Vinlet) 里体现。

4油门缩放与响应

这是最容易误解的一环：热力学循环永远按满油门算，飞行中的油门只做下游缩放。

强制满油门

JetEngineData.UpdatePerformance 把 Throttle 强制写为 1.0。 所以 T04 永远是 burnerTemp，与操纵杆位置无关。

5质量公式与 baseSize 反推

质量由几何经验式计算。用五架机的存档数值反推，确认军用部件的 baseSize 为 0.9。

质量经验式

r = (0.5·size·baseSize) / sqrt(BPR+1) A = π·r² l2 = 1 + max(0,(T4−1388)/2500) l3 = sqrt(max(0, BPR−1)) l4 = 145·(1+1.4·l3) l5 = 360·(1+0.5·l3)·l2 mass = [ π·FanRadius²·0.5·l4 + A·(3.276+0.1·CPR+0.1)·l5 + (有加力 ? A·2.364·150 : 0) + A·2.155·250 ] · 0.01

6调校要点与常见误区

参数影响

参数提高的收益代价 / 约束
bypassRatio风扇推力占比↑，巡航 SFC 更优核心流量↓，核心推力下降
compressionRatio热效率↑、核心推力↑T03 抬升，收益非线性
burnerTemp推力主旋钮质量按 (T4−1388)/2500 增长
size面积、流量、推力近似平方增长质量与迎风阻力同步上升，SFC 不变
afterburner加力推力↑、IR 特征 ×10油耗剧增、质量增加

高频误区

1
改油门调不动推力——循环按满油门算，真正生效的是脚本里的 coreThrottle^2.5。
2
写 afterburnerTemp 无效——新代码不读它，加力温度由 burnerTemp 推出。
3
fanPressureRatio 改了不保存——它在部件定义里，状态 XML 不含该字段。
4
压缩比 24 不是上限——存档中已出现 28.5 与 30，设计器上限由部件定义决定。
5
设计器按 0 键可输出全部站位热力数据（T01–T08、P01–P08、推力、油耗、质量、TSFC），是最快的校准手段。

为什么这组数值均衡

  • 涵道比 0.70：偏低但不极端，超音速单位推力好，巡航 SFC 仍可接受。
  • 压缩比 24.0：接近设计器上限，热效率高但不越界。
  • 燃烧室温度 1800 K：质量与推力的折中点，继续升高会显著增重并恶化油耗。
  • 直径 1.125 m：单发中型机适用，再大会增加迎风阻力与结构重量。
若追求极限推力：可转向 size 1.4 / BPR 0.2 / CPR 14 / T4 1850，推力约 166 kN，但质量升至 31 kg、油耗与尺寸明显上升。本报告给出的是综合最优解。
