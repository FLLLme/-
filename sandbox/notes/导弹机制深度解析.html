1脱锁逻辑总览

主动雷达弹与红外弹共用同一套脱锁机制，差别只在锁之前的签名、灵敏度与射程。

关键结论

两者在“脱锁”层面完全相同。 都走 MissileSeeker.AcquireTarget / MaintainLock；IRSeeker 与 RadarSeeker 只提供 signature 类型、灵敏度、发射提示语三件事。

锁前：获取锁定

rate = clamp( signature / distance × sensitivity, 0, 2 ) rate = max( rate, 0.1 ) // 强制下限 // ContinuousLock 再 ×1.5 — 红外/主动雷达均不适用 lockPercentage += rate × dt
  • 条件：非友军、夹角 ≤ 最大制导角、距离在射程内、未被遮挡、非和平模式、冷却结束。
  • 锁定进度的增长只由上式决定；灵敏度越高、距离越近、签名越强，锁得越快。

锁后：维持与脱锁

每个物理帧调用 MaintainLock，只有三种方式结束锁定：

1
目标死亡 → 清空目标，返回 false
2
干扰概率上升沿判定成功 → 脱锁（下文详述）
3
ContinuousLock 且目标失锁 → 仅半主动弹适用，红外/主动雷达不走这条
锁后不再检查夹角、距离、遮挡、冷却、锁定进度衰减。目标飞出视场或被地形挡住，导弹照样锁定。

2脱锁概率是否逐步叠加

分两层看：目标侧是叠加的，导引头侧是上升沿判定，不是逐帧累加。

目标侧：递减叠加 + 衰减

newBreak = clamp( current + added, 0, 0.9 ) added = breakChance × ( 1 − current ) × EvadeCurve( signature )
  • 每发都乘 (1 − current)，所以是递减叠加，不是线性。
  • 上限钳在 0.9（不是 1.0）。
  • 每发贡献按 0.25/s 消散；默认 breakChance = 0.25、evadeLockChance = 0.5。
  • 干扰弹不注册为独立目标，只改 PlayerTarget 的概率字典。

导引头侧：上升沿触发

if ( breakProb > lastBreakLockChance && IsLocked ) lock = 1 − breakProb roll = Random.Range( 0.1, 1.0 ) if ( lock < roll ) → 清除目标，脱锁 lastBreakLockChance = breakProb // 只赋值，不衰减
瞬时脱锁率 = p / 0.9。 概率不上升就不掷骰子；快照成为“历史峰值”，扛过一次后对同等干扰免疫。代码里衰减的是 _lastTargetBreakChance，而比较用的是 _lastBreakLockChance——后者无衰减路径。

4导弹能否一直锁定

可以。发射后不存在超时、无距离/视角/遮挡复核，只要不触发那次随机脱锁判定，锁定会一直保持。

不会导致脱锁的情况

  • 目标大幅机动、飞出导引头视场、被地形遮挡、飞出原射程 —— 均不复核。
  • 燃料耗尽：OnFuelExhausted 只置 OutOfFuel，不清目标、不置 IsLocked=false。
  • 干扰概率保持不变或下降：不构成上升沿，不掷骰子。
高水位效应：快照 _lastBreakLockChance 没有衰减路径，只有赋值。扛过一次干扰后，后续概率必须超过历史峰值才会再次判定。真正能“扛过去并长期免疫”的窗口在 0.85–0.89 附近（0.9 时几乎必脱锁）。
唯一常态终点：命中、目标被摧毁，或物理上失效。红外/主动雷达发射后即“发射后不管”，不会重新搜索目标。

5转弯 G 力 vs 转弯速率

面板上是两个独立显示、量纲不同的数值：一个是姿态转速（deg/s），一个是轨迹过载（Gs）。

游戏内显示对照

显示项单位游戏内计算式决定因素
转弯速率deg/s MaxHeadingAngleAdjustmentRate + MaxThrustVectoringRate 尾翼/舵面 + 推力矢量
转弯 G 力Gs MaxVelocityAngleAdjustmentRate × π/180 × MaxSpeed / 9.81 尾翼升力/质量 × 最大速度
直线加速（易混淆）Gs Acceleration / 9.81 不是转弯

物理含义

转弯速率 · 姿态
机头指向目标的角速度，决定导引/瞄准响应速度。主要由尾翼面积与力臂决定，低速时还会被 speed/maxSpeed 打折。
转弯 G 力 · 轨迹
飞行方向弯折对应的向心加速度，决定拦截高机动目标时轨迹能否咬住。物理关系 a = ω·v，所以速度越大 G 越高。
关键权衡：MaxSpeed = 引擎MaxSpeed × clamp(1 − 0.2k, 0.25, 1)。尾翼越极端，k 越大反而把速度压得越低（最多 −20%）。高速弹应适度控制尾翼、优先保速度；低速弹才靠大尾翼换 k。

6如何分别提升

两者共享核心因子 k = clamp(尾翼效率 ÷ 质量, 0.05, 2.0)，但侧重不同。

提升转弯速率（deg/s）

  • 增大尾翼面积 — 提高 Σ面积，两者同涨。
  • 尾翼后移 — 加大 z 力臂，同时抬高力臂系数，对 deg/s 增益最大。
  • 增加尾翼数量 / 弦长 — 面积与力臂双升，但增重。
  • 减重（缩小战斗部、减轻引擎）— 两者同涨。
  • 矢量推进引擎 — 只加姿态转速，不加 G 力。

提升转弯 G 力（Gs）

  • 提高 MaxSpeed — 最直接，G 与速度成正比，且不影响 deg/s。
  • 增大尾翼面积 / 后移尾翼 — 提高 k，但受速度惩罚约束。
  • 减重 — 提高 k，无副作用。
最简操作建议：想让弹头快速指向目标 → 尾翼做大、往尾部装，可加矢量推进。想让轨迹急转咬住机动目标 → 优先提高引擎最大速度。两者兼顾 → 减重是唯一同时利好且无副作用的手段。
